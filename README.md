# مراس أثر الموسم | مبادرة نون متحد

موقع عربي تفاعلي (RTL) لعرض أجندة برامج وفعاليات مبادرة **نون متحد** بالشراكة مع **جمعية علم الحج** لموسم 1448هـ - 2026 - 2027م.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح: http://localhost:3000

## البناء للإنتاج

```bash
npm run build
npm start
```

## النشر على GitHub Pages

المشروع مُعد للتصدير الثابت (`output: "export"`). عند الدفع إلى فرع `main` يعمل workflow تلقائيًا ويبني الموقع وينشره.

## المواصفات

- **الإطار:** Next.js 14 (App Router) + TypeScript + Tailwind CSS + Lucide React
- **الاتجاه:** RTL كامل، خط IBM Plex Sans Arabic مع Tajawal كبديل
- **الألوان:** `#855970` أساسي، `#DB949F` و `#D0B8A8` مساندة
- **التوقيت:** كل الحسابات بتوقيت `Asia/Riyadh` (UTC+3 ثابت) — لا يعتمد على جهاز الزائر
- **الحالة تلقائية:** قبل 17:00 قادم، 17:00–19:59 جاري الآن، من 20:00 منتهي
- **تحديث حي:** كل ثانية بدون إعادة تحميل (الإحصائيات + الحالات + العد التنازلي)
- **Responsive:** موبايل 1 / تابلت 2 / سطح مكتب 3 بطاقات
